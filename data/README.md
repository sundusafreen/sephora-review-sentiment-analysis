# Dataset Information

The original dataset contains 519,409 Sephora product reviews.

Due to GitHub file size limitations:
- A sample dataset is included in this repository
- The full dataset can be accessed here:

👉 https://drive.google.com/file/d/1D06ocLFZ_DgIB1vcijbem1B61HLyCU23/view?usp=sharing

Fields include:
- Review text
- Product metadata
- Skin type
- Rating / sentiment labels
